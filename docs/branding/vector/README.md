# Logos vectoriels Radar

Retour à une identité SVG : orbite radar, signal citron et silhouette métier, sans texture raster, effet 3D ni fond opaque.

- ImmoRadar : `frontend/public/immoradar-mark.svg`, intégré à l’en-tête et à la favicon.
- AutoRadar : `frontend/public/autoradar-mark.svg`, prêt pour une application automobile ; non intégré à l’app immobilière.

Les noms restent en texte dans l’interface, pour garder une typographie accessible et nette. Les anciennes explorations PNG sont conservées, pas supprimées. Les SVG sont dessinés directement dans le dépôt, sans génération d’image.
